# Mental Health Breathing Game

A MATLAB-based interactive breathing game designed to help users practice mindfulness and regulate their breathing patterns. The game provides exercises tailored to different mental states and allows users to personalize the pace and repetitions.

## Features
- Three breathing exercises based on user state: **stressed**, **restless**, or **unfocused**
- Real-time visual feedback using a simple game engine (`simpleGameEngine`)  
- Adjustable **tempo** to personalize pacing
- User-defined **repetitions** for each exercise
- Input validation to ensure smooth user experience
- Infinite replayability with option to reset tempo

## Tools & Technologies
- **MATLAB**  
- Custom **game engine functions** for drawing scenes (`drawScene`)  
- Interactive keyboard input handling (`getKeyboardInput`)  
- Looping and timing for guided breathing sequences
